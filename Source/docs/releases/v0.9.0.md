# Shrapwill v0.9.0 — Windows preview

A straightforward local video editor for simple and intermediate projects.
Familiar editing panels, multitrack cuts, titles, transitions, picture controls,
audio adjustments, and MP4 export.

**No account, subscription, in-app purchase, ads, or AI upsells.**

## Install

Download **Shrapwill-0.9.0-Windows-x64-Setup.exe**, run setup, and open Shrapwill.
The installer includes FFmpeg/FFprobe and the local rendering resources.
Microsoft WebView2 is required; setup can download it if it is missing.

Use `SHA256SUMS.txt` to verify the downloaded installer if desired.

## Included in this preview

- Multitrack editing with trim, split, linked clips, locks, and undo/redo.
- Editable static titles, filters, video effects, and overlapping transitions.
- Photographic preview cards and sample playback with fourteen bundled images.
- Independent filter/effect controls, customizable shortcuts, and local projects.
- Original media preservation, local preview caches, and export from originals.

## Known limitations

- This is a preview release; project files from other editors are not supported.
- Titles support static text. Text animation is not available.
- The broad export comparison flags an unresolved mismatch for the existing Ascii Art preset.
- Some historical structural-quality findings remain open.
- The installer is unsigned; Windows may display a publisher/reputation prompt.
