# Shrapwill 0.11.0

This release expands the editing controls and improves everyday timeline work.
Projects and original media remain local, with compatible project loading and
undoable edits.

- Separate Auto Ripple, Magnetic Timeline and Enable timeline snap controls.
  Snapping works with the playhead as well as clips. Invalid overlapping drops
  return to their original position. Zoom and scrolling follow project length,
  and newly opened projects start fitted to the timeline.
- Right-click track creation, selectable interface text and Ctrl+C copying,
  cleaner timeline controls, and a draggable filtered/original comparison in
  filter previews.
- Reorganized Video, Audio, Speed, Animation and Color inspector areas, with
  independent section switches that retain stored adjustments when bypassed.
- Clip motion and keyframe presets; uniform speed, reverse, pitch preservation
  and speed ramps. Repeated speed changes use the original selected range and
  preserve original files.
- Expanded color controls, sharpening, shaped vignettes, secondary curves and
  tone wheels. Preview and export share the supported adjustments. The HDR area
  currently adjusts SDR tones; HDR delivery remains unavailable.
- Audio routing, balance, pitch, equalization, normalization, ducking, noise
  controls and local voice treatments, with matching preview/export processing.
  AI voice tools and cloud processing are unavailable.
- Integrated window controls, refined update settings, and smoother menus and
  dialogs that respect reduced-motion preferences.
- Updated documentation, generated-media regression checks, and a separate
  read-only media comparison utility.

Download the Windows x64 installer for a normal installation, or the portable ZIP
for a self-contained folder. Existing updater-enabled installations can use
Settings → Updates after this release is published. The signed update package
and feed are intended for the application's updater.

Running editor sessions are preserved. Save your work and restart when convenient
to begin using an updated build.
