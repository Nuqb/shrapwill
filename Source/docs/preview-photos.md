# Photographic preset preview sources

Generated using the built-in image generator for Shrapwill. These fictional
photographic scenes replace procedural line art in library cards, hover animation
and sample playback. The real preset renderer supplies the demonstrated result;
the photographs themselves have no pre-applied effects.

Final assets (1280×720 optimized JPEGs, bundled locally):

- `src/features/library/art/assets/harbor-portrait.jpg`
- `src/features/library/art/assets/alpine-portrait.jpg`

The generated PNG originals remain preserved in the image generator's output.
Source packaging includes all final assets through its existing `src` rule.
